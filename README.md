# Financial Modeling & AI logic Audit Portfolio

This repository contains professional-grade Python implementations of US financial modeling standards and systematic audits of AI-generated financial logic. It is designed to demonstrate expertise in **DCF Valuation, 3-Statement Modeling, and GAAP-compliant analysis.**

## 🎯 Project Objectives
- **Financial Accuracy:** Implementing US-based financial frameworks (WACC, CAPM, Gordon Growth).
- **AI Model Auditing:** Demonstrating the ability to identify, document, and fix logical fallacies in automated financial outputs.
- **Code Quality:** Utilizing PEP8 standards, type-hinting, and robust error handling in Python.

## 📁 Repository Structure
- `audits/`: Detailed walkthroughs of identified logic errors in financial scripts.
- `models/`: Python-based valuation and forecasting tools.
- `docs/`: Technical documentation and LaTeX-formatted financial formulas.

## 🛠 Tech Stack
- **Languages:** Python (Pandas, NumPy)
- **Documentation:** Markdown & LaTeX
- **Version Control:** Git (Feature branching and PR workflow)

## 🇺🇸 US Finance Standards
Focus areas include US Federal Tax rates (21%), SEC filing interpretations (10-K/10-Q), and standard valuation methodologies used in US Investment Banking and FP&A.
